# One Dark Pro Darker — Omarchy Theme

Tema [One Dark Pro Darker](https://github.com/Binaryify/OneDark-Pro) para [Omarchy](https://omarchy.org/).

Paleta tomada de [`oneDarkProDarker.ts`](https://github.com/Binaryify/OneDark-Pro/blob/master/src/themes/data/oneDarkProDarker.ts).

| Rol | Color |
|-----|-------|
| Background | `#23272e` |
| Surface / sidebar | `#1e2227` |
| Foreground | `#abb2bf` |
| Accent (blue) | `#61afef` |
| Red / Green / Yellow | `#e05561` / `#8cc265` / `#d19a66` |

## Installation

```bash
omarchy theme install https://github.com/jlopezxs/omarchy-one-dark-pro-darker
```

O, si ya tienes el directorio localmente:

```bash
ln -sfn /home/jlopezxs/code/omarchy-one-dark-pro-darker ~/.config/omarchy/themes/one-dark-pro-darker
omarchy theme set "One Dark Pro Darker"
```
